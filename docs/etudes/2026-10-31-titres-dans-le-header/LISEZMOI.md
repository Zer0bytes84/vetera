# Étude abandonnée : les titres de pages dans le header de l'application

Le 31/10/2026. L'idée était de faire monter le titre de chaque page dans le header de l'application, à côté de l'icône de la barre latérale. Sur le dossier patient, ce titre aurait été le fil d'Ariane « Patients / Kejounti · ID-0010 ». Les gros titres à l'intérieur des pages auraient disparu.

**Décision : abandonnée.** L'application reste telle quelle. Aucun code de la proposition n'a été écrit, et le scénario de capture qui a servi ici a été retiré.

Ce dossier garde seulement l'état actuel des douze pages, vu sur une copie de la base réelle. `mesures.json` donne, pour chaque page, le texte du header et les titres `h1` présents dans la page. Le header n'affiche aucun titre, et chaque page porte le sien à l'intérieur.

Les captures sont en thème sombre. La série prévue en clair est elle aussi sortie en sombre ; la cause n'a pas été cherchée, puisque l'étude s'est arrêtée là.
